# salesforce_custom_metadata_record (Resource)

Manages a Custom Metadata record (any Custom Metadata Type) through the Metadata API.

## Example Usage

```terraform
# Record of MySigningKey__mdt with a Text and a DateTime field.
resource "salesforce_custom_metadata_record" "signing_key" {
  type           = "MySigningKey"
  developer_name = "SigningKey_2026T3"
  label          = "SigningKey_2026T3"

  values = {
    Certificate__c = "SigningKey_2026T3"
    ValidFrom__c   = "2026-11-06T09:00:00Z"
  }
}
```

## Values

`values` maps field API names to strings. The provider looks up each field's type on
the Custom Metadata Type and sends Checkbox (`true`/`false`), Date (`YYYY-MM-DD`) and
DateTime (RFC 3339, e.g. `2026-11-06T09:00:00Z`) with their XML types; every other field
type is sent as a string. A value Salesforce returns in another but equivalent form
(`2026-11-06T09:00:00.000Z`, `7.0`) keeps the configured form in state.

Terraform owns the whole record: every field not listed in `values` is cleared, and a
value changed or set outside Terraform shows as drift and is reverted by the next apply.
An unchecked Checkbox counts as unset, so `Flag__c = "false"` and leaving `Flag__c` out
are the same. Empty strings are not allowed; leave the field out instead.

`terraform plan` fails on a type or field name that does not exist. The check runs when a
record is created or the set of fields in `values` changes.

## Schema

### Required

- `developer_name` (String) Record name (DeveloperName), optionally with a namespace prefix (ns__Name): starts with a letter, only letters, digits and single underscores, no trailing underscore, at most 40 characters without the prefix. Changing it forces a new record.
- `label` (String) Record label, at most 40 characters.
- `type` (String) API name of the Custom Metadata Type without the __mdt suffix, e.g. MyType for MyType__mdt. Changing it forces a new record.

### Optional

- `protected` (Boolean) Whether the record is protected. Defaults to false.
- `values` (Map of String) Field API name -> value, e.g. { Certificate__c = "MyCert", ValidFrom__c = "2026-11-06T09:00:00Z" }. Write Checkbox as true/false, Date as YYYY-MM-DD and DateTime as RFC 3339. The record is owned as a whole: fields not listed are cleared, also when set outside Terraform.

### Read-Only

- `id` (String) Metadata fullName: <type>.<developer_name>.

## Import

Import is supported using the following syntax:

```shell
# Import by <type>.<developer_name> (type without __mdt).
terraform import salesforce_custom_metadata_record.signing_key MySigningKey.SigningKey_2026T3
```

Import reads every field that has a value into `values`. List the same fields in the
configuration, or the next apply clears the ones you left out.
