# salesforce_self_signed_cert (Resource)

Manages a Salesforce-generated self-signed certificate. Salesforce owns the private key; Terraform exposes only public certificate metadata.

## Example Usage

```terraform
resource "salesforce_self_signed_cert" "signing" {
  developer_name = "IntegrationSigningCert"
  master_label   = "Integration Signing Cert"

  key_size               = 2048
  private_key_exportable = false

  # Replace the certificate 30 days before it expires.
  early_renewal_hours = 720
}

# Public certificate for services that verify signatures made by Salesforce.
output "cert_pem" {
  value = salesforce_self_signed_cert.signing.cert_pem
}

# JWKS document, e.g. to serve at a jwks_uri.
output "jwks" {
  value = jsonencode({
    keys = [jsondecode(salesforce_self_signed_cert.signing.jwk)]
  })
}
```

## Renewal

Salesforce self-signed certificates are valid for one year. Once the current time
is within `early_renewal_hours` of `expiration_date`, the next plan replaces the
certificate: the old one is deleted and a new key pair is generated under the
**same `developer_name`**. Because the JWK `kid` is the developer name, the `kid`
stays stable while `n` (the key) changes. `cert_pem`, `cert_sha256` and `jwk` are
unknown during that plan, so anything derived from them (a JWKS, a trust store
entry) is updated in the same apply.

Do not set `create_before_destroy` on this resource: the replacement uses the
same developer name and would collide with the certificate it replaces.

## JWKS

`jwk` is a JSON string (`kty`, `kid`, `use = "sig"`, `alg = "RS256"`, `n`, `e`).
Combine several certificates (here created with `for_each`) into one JWKS:

```terraform
locals {
  jwks = jsonencode({
    keys = [for c in salesforce_self_signed_cert.keys : jsondecode(c.jwk)]
  })
}
```

## Schema

### Required

- `developer_name` (String) API name of the certificate. Also used as the JWK kid. Changing it forces a new certificate.

### Optional

- `early_renewal_hours` (Number) Hours before expiration_date from which the next plan replaces the certificate under the same developer_name. Defaults to 0 (renew once expired).
- `key_size` (Number) RSA key size in bits: 2048 (default) or 4096. Changing it forces a new certificate.
- `master_label` (String) Human-readable label. Defaults to developer_name. Changing it forces a new certificate.
- `private_key_exportable` (Boolean) Whether Salesforce allows exporting the private key. Defaults to false. Changing it forces a new certificate.

### Read-Only

- `cert_pem` (String) Public certificate in PEM format.
- `cert_sha256` (String) SHA-256 fingerprint of the certificate (hex).
- `encrypted_with_platform_encryption` (Boolean) Whether the certificate is encrypted with Shield Platform Encryption.
- `expiration_date` (String) Expiration date (YYYY-MM-DD) set by Salesforce.
- `id` (String) Same as developer_name.
- `jwk` (String) The public key as an RS256 JSON Web Key (JSON string), kid = developer_name. Collect several into a JWKS to publish them side by side.
- `ready_for_renewal` (Boolean) Whether the certificate is within early_renewal_hours of expiring at the last refresh.

## Import

Import is supported using the following syntax:

```shell
# Import by developer name.
terraform import salesforce_self_signed_cert.signing IntegrationSigningCert
```

`early_renewal_hours` is Terraform-only state and imports as `0`; if configured
otherwise, the first plan shows an in-place update that makes no Salesforce call.
