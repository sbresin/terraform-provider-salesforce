# Salesforce Provider

Interact with Salesforce APIs. Currently manages Salesforce-generated certificates
(`salesforce_self_signed_cert`) and reads existing ones (`salesforce_cert`).

## Authentication

Configure exactly one of the following modes, in the provider block or via
environment variables. Mixing both modes is an error.

### Client credentials

An External Client App / Connected App with the client credentials flow enabled:
`instance_url`, `client_id`, `client_secret`
(`SALESFORCE_INSTANCE_URL`, `SALESFORCE_CLIENT_ID`, `SALESFORCE_CLIENT_SECRET`).

### SFDX auth URL

A `force://...` URL holding a refresh token (`auth_url` / `SALESFORCE_AUTH_URL`).
Generate it with the Salesforce CLI:

```shell
sf org auth show-sfdx-auth-url -o <org-alias> --no-prompt
```

### No credentials

Without any credentials the provider still configures successfully; only planning
or applying a resource or data source fails with "Missing Authentication
Configuration". A root module can therefore include the provider in environments
without Salesforce access as long as it creates no instances there (e.g.
`count = 0`).

## Example Usage

```terraform
terraform {
  required_providers {
    salesforce = {
      source = "sbresin/salesforce"
    }
  }
}

# Option A: Client credentials authentication
provider "salesforce" {
  instance_url  = "https://example.my.salesforce.com"
  client_id     = var.salesforce_client_id
  client_secret = var.salesforce_client_secret
}

# Option B: SFDX auth URL authentication (uncomment to use)
# provider "salesforce" {
#   auth_url = var.salesforce_auth_url
# }

variable "salesforce_client_id" {
  description = "Salesforce OAuth client ID"
  type        = string
  sensitive   = true
  default     = ""
}

variable "salesforce_client_secret" {
  description = "Salesforce OAuth client secret"
  type        = string
  sensitive   = true
  default     = ""
}

variable "salesforce_auth_url" {
  description = "Salesforce SFDX auth URL"
  type        = string
  sensitive   = true
  default     = ""
}
```

## Schema

### Optional

- `api_version` (String) The Salesforce API version to use (e.g., v61.0). Can also be set via SALESFORCE_API_VERSION environment variable. Defaults to v61.0.
- `auth_url` (String, Sensitive) The sfdx auth URL (force://...) containing credentials. Can also be set via SALESFORCE_AUTH_URL environment variable. Use this OR the instance_url/client_id/client_secret combination.
- `client_id` (String) The OAuth client ID (Consumer Key) from the Connected App. Can also be set via SALESFORCE_CLIENT_ID environment variable. Required for client_credentials authentication.
- `client_secret` (String, Sensitive) The OAuth client secret (Consumer Secret) from the Connected App. Can also be set via SALESFORCE_CLIENT_SECRET environment variable. Required for client_credentials authentication.
- `instance_url` (String) The Salesforce instance URL (e.g., https://example.my.salesforce.com). Can also be set via SALESFORCE_INSTANCE_URL environment variable. Required for client_credentials authentication.
